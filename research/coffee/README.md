# Выборка кофеен из ГИР БО

Файлы перенесены из архива Никиты после структурной очистки. `gir_bo_coffee.csv` оставляет только строки с десятизначным ИНН, выручкой 3–60 млн ₽, себестоимостью ниже выручки, ссылками и без повтора ИНН за год.

`candidates.csv` содержит 74 уникальных кандидата из Москвы и Тулы с URL поиска места. Названия и адреса в исходном архиве были названиями организаций ГИР БО, поэтому перед использованием как выборки именно кофеен требуется ручная сверка карточки места, формата и единственной точки.
