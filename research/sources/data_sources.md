# Каталог источников данных

Каталог составлен Иваном по задаче S1-I1 для Москвы в пределах МКАД и Тулы, машиночитаемая версия лежит в `data_sources.csv`. Проверка выполнена 2026-10-15 через поиск и чтение найденных страниц. Автоматическое чтение data.mos.ru запрещено файлом robots.txt портала, поэтому паспорт набора общепита, условия использования портала и раздел открытых данных Тульской области Фёдор проверил вручную в тот же день, а API Работы России проверено работой конвейера. Сведения по Реформе ЖКХ и ГИС ЖКХ остаются неподтверждёнными. Какие источники уже загружает конвейер, описано в `docs/data-sources.md`.

В каталоге применяются три статуса. Статус «подтверждено» означает, что факт виден на странице владельца или площадки раздачи. Статус «вторичный источник» означает пересказ третьей стороной. Статус «не подтверждено» означает, что проверка не завершена. Юридическая оценка лицензий не проводилась.

## Описание источников

### OpenStreetMap и Geofabrik

Выгрузка Geofabrik для Центрального федерального округа содержит Москву и Тулу в одном файле и раздаётся без ключа и регистрации. Страница раздачи показывает ежедневные снимки с именами вида `central-fed-district-260605.osm.pbf`, а файлы очищены от имён авторов правок. Из выгрузки конвейер берёт полигоны зданий, адресные теги, кафе, пункты выдачи, остановки и входы в метро по тегам из `config/niches.yaml`. Лицензия ODbL требует указывать авторство и распространять производные базы на тех же условиях, поэтому для банка нужно отдельно решить, как трактуется внутренняя база признаков ячеек при передаче третьим лицам. Конвейер ГеоСтарта закреплён на снимке `central-fed-district-261013.osm.pbf` от 13.10.2026 размером 881 МБ. Зеркало download.openstreetmap.fr отдаёт тот же округ более свежим снимком и служит запасным источником. Москва внутри МКАД вырезается по полигону из самой выгрузки.

### data.mos.ru, общественное питание

Набор 1903 ведёт Департамент торговли и услуг Москвы. Паспорт описывает стационарные предприятия общественного питания в границах Москвы, набор впервые опубликован 16.09.2015, версия 1.319 вышла 13.10.2026. В паспорте указана периодичность «ежеквартально», но новые версии выходят каждую неделю. Структура `structure-20220915T1516(v1).json` содержит поля `Name`, `IsNetObject`, `OperatingCompany`, `TypeObject`, `AdmArea`, `District`, `Address`, `PublicPhone`, `SeatsCount`, `SocialPrivileges`, `Longitude_WGS84`, `Latitude_WGS84` и геометрию. В версии от 13.10.2026 22 857 записей, координаты есть у всех, число мест больше нуля у 80 %. Архив выгрузки скачивается по ссылке из метаданных набора без ключа и регистрации, ключ apidata.mos.ru нужен только для API. Условия портала относят все материалы к открытым данным по постановлению Правительства РФ № 583 от 10.07.2013 и разрешают повторное использование со ссылкой на портал. Старые наборы по кофейням и столовым помечены архивными и в расчёт не берутся, поэтому кофейни отбираются из набора 1903 по названию.

### data.mos.ru, Адресный реестр объектов недвижимости

Реестр хранит пространственно привязанные адреса земельных участков, зданий, сооружений и помещений Москвы, его обновляет МосгорБТИ. В списке портала набор отмечен актуализированным в октябре 2026 года и снабжён картой. Присутствие явных координат в выгрузке не проверено, хотя привязка к карте заявлена. Набор служит лучшим кандидатом для координат домов Москвы.

### data.mos.ru, нестационарная торговля и пункты выдачи

Набор о нестационарных торговых объектах на территории парков найден только в версии ноября 2021 года и для ГеоСтарта устарел. Полный набор схемы размещения нестационарных объектов и набор пунктов выдачи заказов поиском не найдены. Конкуренты ниши пунктов выдачи берутся из OpenStreetMap по тегу `shop=outpost`, а наличие таких данных у маркетплейсов и условия их повторного использования не проверялись. Набор о населении районов Москвы в выдаче тоже не появился, для района используются данные Мосстата.

### Реформа ЖКХ

Портал Минстроя России хранит карточки многоквартирных домов. По описанию стороннего сервиса карточка содержит тип дома, общую площадь, этажность, износ и число помещений разных типов, а выгрузка доступна через операции в карточке. Открытые данные портала использует Яндекс Облако в готовом датасете об аварийных объектах с полями года постройки, региона, типа стен, площади и этажности. Координаты в выгрузке, формат пакетной загрузки, лицензия и необходимость ключа не подтверждены. Дома для ячеек H3 придётся привязывать по адресу.

### ГИС ЖКХ

Открытая часть системы содержит реестр объектов жилищного фонда с техническими характеристиками домов, справка системы указывает кнопку скачивания архива реестра. По стороннему описанию карточка включает адрес, кадастровый номер, год постройки, этажность, число квартир и подъездов, общую и жилую площадь и управляющую организацию. Координаты, формат архива и лицензия не подтверждены, а часть сведений требует входа через Госуслуги. Для числа квартир по домам система остаётся основным кандидатом.

### ГАР ФНС

ГАР заменил ФИАС после прекращения его обновления в 2021 году и распространяется бесплатно в формате XML. Реестр содержит адреса и кадастровые номера домов, но координат в нём нет, а по сообщению автора публикации на Хабре координаты берут из OpenStreetMap и кадастровой карты. Справочник 1С подтверждает актуальность реестра на июль 2026 года. Условия использования на странице загрузки не проверены.

### Росстат, БД ПМО, ЕМИСС и ВПН-2020

Росстат публикует таблицы численности населения по муниципальным образованиям на 1 января каждого года, в выдаче найдены таблицы до 2024 года включительно. Таблица на 1 января 2026 года для Москвы и Тулы не подтверждена, на старте используются данные Мосстата по Москве и Туластата по Тульской области. Жилищный фонд по муниципальным образованиям лежит в БД ПМО в разделе коммунальной сферы, а показатели из Реформы ЖКХ дублируются в ЕМИСС. Показатели по домам в этих базах отсутствуют, поэтому они годятся для калибровки сумм по округу. Средний размер домохозяйства для Москвы и Тулы берётся из региональных таблиц ВПН-2020 о числе и составе домохозяйств, значения для двух городов в этой сессии не получены.

### Туластат и открытые данные Тульской области

Территориальный орган Росстата выпускает ежемесячный доклад о социально-экономическом положении Тульской области с разделами о розничной торговле и уровне жизни, найден выпуск за январь-май 2026 года. Доклад даёт региональные контрольные цифры и не содержит данных по ячейкам. Раздела открытых данных на сайте правительства области нет, адрес tularegion.ru/opendata отвечает ошибкой 404 (проверено 2026-10-15). Реестра адресов с координатами и списка заведений общепита по Туле подтвердить не удалось, поэтому для Тулы основой остаются OpenStreetMap, ГАР и ГИС ЖКХ. Нужен запрос в профильное ведомство региона и администрацию города.

### Работа России

Портал trudvsem.ru ведёт общероссийскую базу вакансий. По описанию стороннего сборщика открытое API отдаёт вакансии постранично с полями должности, работодателя с ИНН и ОГРН, вилки зарплаты и региона. Конвейер ГеоСтарта запрашивает API без ключа, лимиты и лицензия не подтверждены. Ответ содержит контакты работодателя, поэтому в кэш попадают только идентификатор, название, вилка зарплаты и дата. Государственные и муниципальные организации, а также работодатели с численностью выше порогового значения обязаны размещать вакансии только на этом портале, тогда как небольшие кофейни могут публиковать их на других площадках. Выборка по баристам и операторам пунктов выдачи смещена к крупным работодателям. Квартили зарплат p25-p50-p75 считаются по границам вилок.

### ГИР БО

Ресурс ФНС даёт бесплатный поиск отчётности организации по ИНН, ОГРН, адресу, наименованию и коду ОКВЭД2, а полный массив выдаётся по платному абонементу по сведениям отраслевого издания 2021 года. Официального бесплатного API в выдаче нет, неофициальные запросы к сайту создают риск нарушения условий использования и в банковском продукте недопустимы. Адрес в ГИР БО относится к юридическому лицу и не определяет положение точки, а организация вправе ограничить доступ к своей отчётности. Выручка юрлица совпадает с выручкой точки только для компаний с одной точкой, критерий отбора для проверки модели нужно задать отдельно. Для пунктов выдачи ГИР БО служит источником выплат маркетплейсов, как показала публикация Коммерсанта по отчётности Wildberries.

### ЕРМСП и данные ФНС

ФНС публикует реестр субъектов МСП открытым набором в XML. Набор включает наименование или ФИО, ОГРН, ИНН, дату регистрации и виды деятельности по ОКВЭД. Реестр даёт число МСП по ОКВЭД в городе. Положение точки по нему не определяется, потому что производный набор каталога data.rcsi.science хранит адрес только до населённого пункта. ФИО индивидуальных предпринимателей относятся к персональным данным, а MVP их не обрабатывает, поэтому при загрузке остаются только ОКВЭД, дата и населённый пункт. В списке открытых данных ФНС по приказу 2017 года числится также ЕГРЮЛ с адресом и ОКВЭД, доступность этого набора в 2026 году не проверена. Каталог data.rcsi.science содержит реестр МСП за 2016-2024 годы с доходами, расходами и численностью работников, в основном за 2019-2023 годы, под лицензией CC BY-SA 4.0. Координаты в нём относятся к населённому пункту, поэтому набор подходит для распределения выручки небольших кофеен по городу, а не для ячеек карты.

### Аренда торговых помещений

По Москве основные ставки и вакантность публикуют NF Group и IBC Real Estate, обзоры пересказывают РБК, Ведомости и Sostav. Обзоры покрывают двенадцать основных торговых улиц и не дают ставок по районам, для районов вне центра остаются объявления площадок с пометкой «ориентир». По Туле аналитического отчёта по ставкам найти не удалось, остаются объявления Яндекс Недвижимости, которые собираются вручную по территориальным округам.

### Data Insight и пункты выдачи

Страницу отчёта Data Insight о рынке пунктов выдачи открыть не удалось. Показатели Data Insight по электронной торговле найдены в пересказе доклада конференции 2026 года. Число пунктов выдачи публикуют INFOLine-Аналитика и маркетплейсы, а их цифры расходятся. Эксперт приводит для Ozon 41 тыс. пунктов, а New Retail сообщает о более чем 78 тыс. по итогам третьего квартала 2025 года, различие вероятно вызвано разным определением пункта, но это не проверено. Для модели ГеоСтарта число конкурентов в радиусе берётся из карты OpenStreetMap, а публикации служат для контроля полноты.

## Жители и работающие по зданиям

Для числа жителей по зданиям лучшим источником выглядит ГИС ЖКХ, потому что реестр объектов жилищного фонда по стороннему описанию содержит число квартир и площадь по каждому дому. Реформа ЖКХ даёт площадь, этажность и число помещений и служит запасным источником и средством перекрёстной проверки. Число жителей дома равно числу квартир, умноженному на средний размер домохозяйства из таблиц ВПН-2020 по региону. Сумма по району затем калибруется под население района по Мосстату для Москвы и под население городского округа по Росстату для Тулы. Для частных домов и домов без записи в ГИС ЖКХ контракт предусматривает запасной вариант, то есть площадь жилых зданий из OpenStreetMap, делённую на норму площади на человека. Норма площади в этой сессии не найдена, поле получает `source: null`.

Для числа работающих по зданиям ни один открытый источник не даёт значения по адресу. Лучшая доступная оценка строится из трёх слоёв. Первый слой даёт валовую площадь нежилых зданий из OpenStreetMap, то есть площадь полигона, умноженную на этажность, для типов `office`, `commercial`, `retail` и `industrial`, при этом норма площади на работающего требует отдельного источника. Второй слой калибрует сумму работающих по муниципальному образованию по БД ПМО, наличие подходящего показателя среднесписочной численности в базе нужно проверить. Третий слой использует признаки `offices_n`, `malls_n` и `education_n` из контракта как веса при распределении внутри района. Производный набор ЕРМСП с численностью работников даёт контроль порядка величины по населённому пункту. Погрешность такой оценки велика и измеряется сравнением с контрольными районами Москвы, где известны крупные работодатели.

## Привязка домов к координатам без платных сервисов

ГАР и ГИС ЖКХ содержат адреса без подтверждённых координат, поэтому координаты берутся из открытых слоёв. Порядок такой.

1. Адреса ГИС ЖКХ, Реформы ЖКХ и ГАР приводятся к единому ключу из названия улицы, номера дома, корпуса и строения после нормализации типов улиц, регистра и буквы «ё».
2. Для Москвы к ключу присоединяются координаты из Адресного реестра data.mos.ru, а несопоставленные дома дополняются из OpenStreetMap.
3. Для Тулы и остатка Москвы используются здания OpenStreetMap с тегами `addr:street` и `addr:housenumber`, координатой служит центроид полигона. Покрытие по России составляет около четверти домов ГАР по публикации на Хабре, для двух городов покрытие нужно измерить заново.
4. Оставшиеся адреса геокодируются локально. Для этого внутри контура разворачивается Nominatim или Photon на выгрузке Geofabrik, внешние API при работе не вызываются.
5. Кадастровый номер дома из ГАР позволяет искать геометрию здания в НСПД Росреестра. Условия автоматической выгрузки не проверены, поэтому приём применяется только после юридической проверки.
6. Доля привязанных домов и квартир считается по районам и записывается в `docs/data-sources.md`, а жители непривязанных домов распределяются по району пропорционально площади жилых зданий.
