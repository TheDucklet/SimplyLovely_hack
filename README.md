# ГеоСтарт

ГеоСтарт оценивает, окупится ли офлайн-точка малого бизнеса на выбранном месте, и показывает ожидаемую выручку, расходы, срок окупаемости и уровень риска по ячейкам карты. Проект разрабатывает команда Simply Lovely на хакатоне «Финтех без границ» (ВТБ и Финансовый университет).

## Что это и для кого

Сервис рассчитан на начинающих предпринимателей, которые открывают кофейню или пункт выдачи заказов, и на сотрудников банка, оценивающих бизнес-план заёмщика. MVP первого спринта охватывает Москву в пределах МКАД и Тулу. API отвечает по реальным данным и расчётам модели, а для разработки интерфейса без данных включается режим заглушек.

## Требования

| Компонент | Версия |
| --- | --- |
| ОС | Windows 10 и новее, Linux или macOS |
| Python | 3.13 (uv скачает его сам по файлу `.python-version`) |
| uv | 0.5 и новее |
| Node.js | 20 LTS, нужен только для `web/` |
| Память | 4 ГБ свободной оперативной памяти для синтетических данных |

На Python 3.12 под Windows пакет не импортируется, если в пути к клону есть кириллица, поэтому проект закреплён на 3.13.

## Установка и запуск

Установка зависимостей:

```
uv sync
```

Синтетические данные для двух городов в `data/processed/`:

```
uv run python -m geostart.pipeline.fixtures --city all
```

Реальные данные OpenStreetMap, портала открытых данных Москвы и Работы России собирает конвейер. Первый запуск скачивает 881 МБ и занимает около 5 минут, параметры лежат в `config/pipeline.yaml`:

```
uv run python -m geostart.pipeline run --city all
```

Расчёт карты по всем городам и нишам (около 30 секунд):

```
uv run python -m geostart.model score --city all --niche all
```

API на `http://127.0.0.1:8000`, документация OpenAPI на `http://127.0.0.1:8000/docs`:

```
uv run uvicorn geostart.api.main:app --reload
```

Проверки перед pull request:

```
uv run ruff format --check
uv run ruff check
uv run pytest
```

## Настройка

Параметры задаются переменными окружения, пример лежит в `.env.example`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEOSTART_USE_MOCKS` | `false` | `true` включает ответы по синтетическим данным для разработки интерфейса без данных |
| `GEOSTART_STORAGE` | `files` | `postgres` переключает карту, конкурентов и поиск на базу, параметры базы описаны в docs/storage.md |
| `GEOSTART_DATA_DIR` | `data/` в корне репозитория | каталог данных |
| `GEOSTART_CONFIG_DIR` | `config/` в корне репозитория | каталог с `cities.yaml` и `niches.yaml` |
| `GEOSTART_CORS_ORIGINS` | `http://localhost:5173` | адреса интерфейса, которым разрешены запросы к API, через запятую |

Города и ниши описаны в `config/cities.yaml` и `config/niches.yaml`. Параметры ниш, ставки аренды и налоги лежат в `research/`, до результатов исследования там стоят условные значения с пометкой `status: placeholder`.
