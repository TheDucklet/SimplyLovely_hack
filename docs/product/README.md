# Продуктовые материалы

Документы подготовил Никита (S1-N1, S1-N2, S1-N3, запуск S1-N5) с помощью Gemini, Фёдор перенёс их в репозиторий 2026-10-16 после правок. Выборочная проверка источников подтвердила ключевые числа: сервис «Оценка потенциала локации» МБМ (mos.ru, 08.08.2026), регистрации и ликвидации юрлиц в 2025 году (Sostav, 26.01.2026), бесплатная «Геоаналитика» Яндекс Карт без расчёта выручки (Click.ru, 11.10.2024).

| Файл | Содержание |
| --- | --- |
| [problem.md](problem.md) | проблема выбора места, гипотезы H1-H5, работы клиента для трёх ролей, измеримая ценность, УТП и отличия от конкурентов |
| [market.md](market.md) | TAM, SAM и SOM с формулами и допущениями, охват сценария кредитного специалиста, разбор восьми конкурентов |
| [competitors.csv](competitors.csv) | сравнение восьми геоаналитических сервисов по 12 признакам |
| [metrics.md](metrics.md) | главная метрика, воронка пилота, текущее качество модели и цели пилота, метрики доверия, расчёт выборки A/B-теста |
| [survey.md](survey.md) | анкета опроса предпринимателей из 11 вопросов для Яндекс Форм и сообщение для чатов |

Раздел о конкурентах в `market.md` взят из первой версии документа, так как во второй версии он оборвался на середине. Значения ROC AUC в `metrics.md` соответствуют проверке модели S1-R4 на 16.10.2026 и обновляются после S1-R5. Итоги интервью и опроса (S1-N4, S1-N5) добавятся сюда 30.10.
