# Демо-стенд

Стенд поднимает API и собранный интерфейс одной командой в Docker. Он нужен для записи видео, показа жюри и проверки развёртывания без среды разработки.

## Состав

| Контейнер | Образ | Что делает |
| --- | --- | --- |
| `api` | `docker/api/Dockerfile`, Python 3.13 и зависимости из `uv.lock` без группы dev | при старте проверяет данные, пересчитывает карту, если расчёты старше данных или исследования, и запускает FastAPI на порту 8000 внутри сети стенда |
| `web` | `docker/web/Dockerfile`, сборка `web/` на Node.js 20 и nginx 1.27 | отдаёт интерфейс и проксирует `/api/` в контейнер `api`, сжимает ответы gzip |

Наружу открыт только порт интерфейса на `127.0.0.1`, API доступен через него по адресу `/api/v1`. Данные в образ не входят, каталог `data/` подключается томом, поэтому новый архив данных подхватывается перезапуском без пересборки.

## Запуск

1. Установите Docker Desktop (Windows, macOS) или Docker Engine с плагином compose (Linux).
2. Распакуйте архив данных команды в корень репозитория, должен появиться каталог `data/processed/` с папками `moscow` и `tula`.
3. Запустите стенд:

```
docker compose -f compose.demo.yml up -d --build --wait
```

4. Откройте `http://127.0.0.1:8080`.

Первая сборка образов занимает около 5 минут и скачивает около 2 ГБ, повторный запуск без изменений кода занимает около 25 секунд, включая пересчёт карты. Остановка стенда:

```
docker compose -f compose.demo.yml down
```

## Настройка

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEOSTART_DEMO_PORT` | `8080` | порт интерфейса на `127.0.0.1` |
| `GEOSTART_MAP_STYLE_URL` | пусто | адрес стиля подложки MapLibre, при пустом значении используется векторный стиль OpenFreeMap Positron на данных OpenStreetMap; меняется при сборке образа `web` |

Переменные задаются в `.env` в корне репозитория или в окружении перед командой запуска.

## Работа без интернета

Во время работы стенд обращается наружу только за тайлами подложки карты, с 2026-11-01 к `tiles.openfreemap.org` (стиль, векторные тайлы и шрифты). Для контура банка в `GEOSTART_MAP_STYLE_URL` указывается собственный сервер тайлов, после чего внешних запросов не остаётся. Сборка образов скачивает пакеты Python и npm, внутри контура её выполняют из зеркала пакетов.

## Проверка

| Шаг | Ожидаемый результат |
| --- | --- |
| открыть `http://127.0.0.1:8080` | карта Москвы с ячейками и конкурентами, внизу версия данных |
| найти «Тверская 7» и выбрать адрес | отчёт по адресу открывается справа примерно за 2 секунды |
| `docker compose -f compose.demo.yml logs api` | строки расчёта четырёх сочетаний города и ниши и запуск uvicorn |

Если в `data/processed/` нет данных, контейнер `api` завершается с сообщением, куда распаковать архив, а команда с `--wait` ждёт до таймаута. В таком случае посмотрите `docker compose -f compose.demo.yml logs api`.
