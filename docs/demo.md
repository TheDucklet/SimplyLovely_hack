# Демо-стенд

Стенд поднимает API и собранный интерфейс одной командой в Docker. Он нужен для записи видео, показа жюри и проверки развёртывания без среды разработки.

## Состав

| Контейнер | Образ | Что делает |
| --- | --- | --- |
| `api` | `docker/api/Dockerfile`, Python 3.13 и зависимости из `uv.lock` без группы dev | при старте проверяет данные, пересчитывает карту, если расчёты старше данных или исследования, и запускает FastAPI на порту 8000 внутри сети стенда |
| `web` | `docker/web/Dockerfile`, сборка `web/` на Node.js 20 и nginx 1.27 | отдаёт интерфейс, стиль и шрифты подложки из `docker/web/basemap/`, проксирует `/api/` в контейнер `api` и `/basemap/tiles/` в контейнер `tiles`, сжимает ответы gzip |
| `tiles` | `protomaps/go-pmtiles:v1.31.2` | отдаёт векторные тайлы подложки из `data/basemap/geostart.pmtiles` |

Наружу открыт только порт интерфейса на `127.0.0.1`, API доступен через него по адресу `/api/v1`. Данные в образ не входят, каталог `data/` подключается томом, поэтому новый архив данных подхватывается перезапуском без пересборки.

## Запуск

1. Установите Docker Desktop (Windows, macOS) или Docker Engine с плагином compose (Linux).
2. Распакуйте архив данных команды в корень репозитория, должен появиться каталог `data/processed/` с папками городов и файл подложки `data/basemap/geostart.pmtiles`.
3. Запустите стенд:

```
docker compose -f compose.demo.yml up -d --build --wait
```

4. Откройте `http://127.0.0.1:8080`.

Первая сборка образов занимает около 5 минут и скачивает около 2 ГБ, повторный запуск без изменений кода занимает около 25 секунд, включая пересчёт карты. Остановка стенда:

```
docker compose -f compose.demo.yml down
```

## Настройка

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEOSTART_DEMO_PORT` | `8080` | порт интерфейса на `127.0.0.1` |
| `GEOSTART_MAP_STYLE_URL` | `/basemap/style.json` | адрес стиля подложки MapLibre, по умолчанию собственная подложка стенда; меняется при сборке образа `web` |

Переменные задаются в `.env` в корне репозитория или в окружении перед командой запуска.

nginx отдаёт index.html с заголовком Cache-Control: no-cache, поэтому после пересборки браузер сверяет страницу с сервером и подхватывает новую версию без очистки кэша. Файлы в /assets/ кэшируются на 30 дней, их имена меняются при каждой сборке.

## Работа без интернета

С 2026-11-20 стенд во время работы не обращается к внешним адресам. Подложка карты состоит из трёх частей:

- векторные тайлы Protomaps (сборка 20261117, схема v4) по прямоугольникам шести городов с запасом 0,02°, масштабы 0-14, файл `data/basemap/geostart.pmtiles` около 105 МБ;
- стиль `docker/web/basemap/style.json`, его собирает скрипт `scripts/basemap_style.py`, все адреса в нём относительные;
- шрифты Noto Sans Medium и Italic из `protomaps/basemaps-assets` для латиницы, кириллицы и знаков препинания, лицензия OFL лежит рядом с ними.

Тайлы крупнее 14 масштаба MapLibre растягивает из 14. Для отсутствующих тайлов сервер отвечает 204, для отсутствующих диапазонов шрифтов nginx отдаёт пустой файл, поэтому символы вне латиницы и кириллицы не выводятся, но и не ломают карту.

Файл тайлов пересобирается командой

```
uv run python scripts/basemap_extract.py
```

Скрипт читает границы городов из `data/processed/<город>/boundary.geojson`, находит нужные тайлы в каталоге сборки Protomaps и скачивает их частями по 20 КБ в 32 потока. Мелкие части понадобились потому, что из нашей сети длинные ответы `build.protomaps.com` обрываются после 20-26 КБ и `pmtiles extract` не завершается. Там, где сеть не режет ответы, тот же файл даёт команда `pmtiles extract https://build.protomaps.com/20261117.pmtiles data/basemap/geostart.pmtiles --region=<границы> --maxzoom=14`.

Сборка образов по-прежнему скачивает пакеты Python и npm, внутри контура её выполняют из зеркала пакетов. Отсутствие внешних запросов проверяют тесты `tests/test_offline.py`. Они запрещают сокетам соединения с адресами вне `127.0.0.1` и проходят по всем путям API, проверяют, что стиль совпадает с генератором и не содержит внешних адресов, что для каждого шрифта стиля есть кириллица и что nginx проксирует запросы только в `api` и `tiles`.

## Проверка

| Шаг | Ожидаемый результат |
| --- | --- |
| открыть `http://127.0.0.1:8080` | карта Москвы с ячейками и конкурентами, внизу версия данных |
| вкладка «Сеть» инструментов разработчика после прокрутки и приближения карты | все запросы идут на `127.0.0.1:8080` |
| найти «Тверская 7» и выбрать адрес | отчёт по адресу открывается справа примерно за 2 секунды |
| `docker compose -f compose.demo.yml logs api` | строки расчёта четырёх сочетаний города и ниши и запуск uvicorn |

Если в `data/processed/` нет данных, контейнер `api` завершается с сообщением, куда распаковать архив, а команда с `--wait` ждёт до таймаута. В таком случае посмотрите `docker compose -f compose.demo.yml logs api`.

Публичный стенд на сервере с ограничениями по памяти и процессору описан в [vps.md](vps.md).
