# Доработка материалов Никиты

Ветка объединяет материалы архивов Никиты с текущими контрактами репозитория. Числовые значения с `source: null` сохранены только там, где промт разрешает командное допущение, и сопровождаются пояснением в `note`.

| Код | Что перенесено или исправлено |
| --- | --- |
| S2-Б3 | Правовой черновик `docs/compliance.md`, ссылка из `docs/security.md` и README |
| S2-Ц2 | Перенесены только разделы `ausn` и `patent_system`; остальные разделы текущего справочника сохранены |
| S2-Ц3 | Добавлены кредитные продукты ВТБ, программы МСП и гранты с явной маркировкой неподтверждённых условий |
| S2-Ц6 | Справка тарифов и параметр `max_orders_per_day` проверены; неподтверждённые тарифы оставлены допущениями |
| S2-Ц7 | Оставлены 74 кандидата с требуемой схемой и 39 строк ГИР БО после числовой фильтрации |
| S2-Ц8 | Нормативы обновлены, ниша `pickup_point_multi` сохранена |
| S2-Т4 | Добавлены источники из архива без замены ранее откалиброванных числовых значений |
| PATCH | Добавлена подстановка городских диапазонов верхнего уровня и общий поиск патентных ключей |

Для S2-Ц7 в `research/coffee/README.md` зафиксировано ограничение исходного архива: названия кандидатов были переданы как названия организаций ГИР БО, поэтому формат заведения и единственную точку нужно подтвердить по карточке места перед использованием выборки в калибровке.

Проверки выполняются командами `uv run pytest`, `uv run ruff check`, `uv run ruff format --check`, `git diff --check` и валидатором паспорта данных.
