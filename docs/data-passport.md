# Паспорт данных

Документ собирается командой `uv run python -m geostart.quality passport` из `config/data_passport.yaml` и `config/pipeline.yaml`. Проверки полноты и диапазонов и отчёт о качестве описаны в [quality.md](quality.md).

## OpenStreetMap, выгрузки Geofabrik по федеральным округам

| Поле | Значение |
| --- | --- |
| Владелец | участники OpenStreetMap, раздача Geofabrik GmbH |
| Где взять | https://download.geofabrik.de/russia.html |
| Лицензия и условия | Open Database License 1.0, подпись «© участники OpenStreetMap» на карте и в отчёте, производная база распространяется на тех же условиях |
| Что берём | здания с типом и этажностью, точки интереса, остановки, входы в метро, административные границы, МКАД, адреса, конкуренты всех ниш |
| Файлы | `hex_features.parquet`, `competitors.parquet`, `addresses.parquet`, `boundary.geojson` |
| Покрытие | Москва, Тула, Ярославль, Санкт-Петербург, Новосибирск, Екатеринбург |
| Версия | дата выгрузки в имени файла и в блоке osm_extracts файла config/pipeline.yaml |
| Как обновить | новая выгрузка подключается заменой url, file и date в config/pipeline.yaml, затем `python -m geostart.release rebuild --city <город>` |
| Частота обновления | Geofabrik обновляет выгрузки ежедневно, сервис закрепляет дату выгрузки и обновляет её перед выпуском версии данных |

## Открытое API портала «Работа России»

| Поле | Значение |
| --- | --- |
| Владелец | оператор портала «Работа России» |
| Где взять | https://opendata.trudvsem.ru/api/v1/vacancies |
| Лицензия и условия | условия повторного использования на портале не указаны, сервис хранит только агрегаты зарплат по профессии без работодателей и контактов |
| Что берём | медиана и квартили зарплат в вакансиях по профессиям ниш |
| Файлы | `wages.parquet` |
| Покрытие | Москва, Тула, Ярославль, Санкт-Петербург, Новосибирск, Екатеринбург |
| Версия | дата сбора в поле collected_at файла wages.parquet |
| Как обновить | `python -m geostart.pipeline wages --city <город>` или пересчёт города без --skip-wages |
| Частота обновления | вакансии меняются ежедневно, зарплаты обновляются перед выпуском версии данных |

## Численность населения

| Поле | Значение |
| --- | --- |
| Владелец | Росстат и территориальные органы статистики, часть чисел взята из публикаций СМИ и сводок со ссылкой на Росстат, для районов Москвы сводка Википедии |
| Где взять | ссылки по каждому городу в разделе «Покрытие и версии» |
| Лицензия и условия | официальная статистика, общедоступная информация |
| Что берём | численность населения города и региона для калибровки жителей ячеек |
| Файлы | `hex_features.parquet` |
| Покрытие | Москва, Тула, Ярославль, Санкт-Петербург, Новосибирск, Екатеринбург |
| Версия | дата оценки численности в config/pipeline.yaml |
| Как обновить | новые числа записываются в population_region и population_scope файла config/pipeline.yaml, затем пересчёт города |
| Частота обновления | Росстат публикует оценку численности раз в год |
