# Качество данных

Каждая версия данных проходит автоматические проверки полноты и диапазонов. Источники с лицензиями, версиями и способом обновления описаны в [паспорте данных](data-passport.md), он собирается из `config/data_passport.yaml` и `config/pipeline.yaml`.

## Команды

```
uv run python -m geostart.quality check --city all
uv run python -m geostart.quality report --output data/quality.md
uv run python -m geostart.quality passport
```

`check` выводит непройденные проверки и завершается с кодом 1, если есть ошибки. `report` пишет отчёт о качестве со сводкой по городам, заполненностью необязательных полей, замечаниями и итогами всех проверок. `passport` обновляет `docs/data-passport.md`, тест `tests/test_quality.py` следит, чтобы паспорт совпадал с настройками.

Проверки встроены в выпуск данных ([release.md](release.md)). Команда `python -m geostart.release rebuild` после пересчёта проверяет города и при ошибках возвращает прежние файлы так же, как при расхождениях выше порогов, отчёт кладётся рядом в `data/releases/<версия>/quality.md`. Команда `package` не собирает архив при ошибках без флага `--force` и кладёт отчёт в архив как `data/quality.md`.

## Уровни

Ошибка означает, что данные нарушают схему или дают заведомо неверный расчёт, такая версия не выпускается. Предупреждение означает, что данные пригодны, но неполны или устарели, оно попадает в отчёт и не останавливает выпуск.

## Проверки

| Набор | Проверка | Уровень |
| --- | --- | --- |
| `boundary.geojson` | многоугольник непустой и корректный | ошибка |
| `hex_features.parquet` | есть все поля и строки | ошибка |
| | ячейки H3 корректны, разрешения города из `config/cities.yaml` и не повторяются | ошибка |
| | центр ячейки внутри прямоугольника границы с запасом 0,02° | ошибка |
| | нет пропусков в жителях, работающих и счётчиках, значения не отрицательные | ошибка |
| | расстояние до метро от 0 до 5000 м там, где оно заполнено | ошибка |
| | счётчики объектов не больше 2000 на ячейку | предупреждение |
| | ячеек без жителей не больше 30% | предупреждение |
| | ячеек без района не больше 10% | предупреждение |
| `competitors.parquet` | есть все поля, ниша из `config/niches.yaml`, источник `osm` или `mos_ru` | ошибка |
| | объект не повторяется внутри ниши | ошибка |
| | координаты внутри границы, ячейка есть в сетке города | ошибка |
| | посадочные места не отрицательные | ошибка |
| | есть конкуренты каждой ниши | предупреждение |
| `addresses.parquet` | адрес не пустой, координаты внутри границы, ячейка есть в сетке | ошибка |
| `wages.parquet` | есть все поля, p25 ≤ p50 ≤ p75, медиана от 15 000 до 400 000 ₽, дата сбора не в будущем | ошибка |
| | есть зарплата каждой профессии из параметров ниш | предупреждение |
| | не меньше 3 вакансий на профессию | предупреждение |
| | зарплаты собраны не раньше 180 дней назад | предупреждение |
| `scores/<город>_<ниша>.parquet` | есть все поля, расчёт покрывает все ячейки сетки | ошибка |
| | выручка p10 ≤ p50 ≤ p90, выручка p50 от 0 до 50 млн ₽ в месяц, уровень риска из справочника | ошибка |
| | расчёт ниши есть | предупреждение |

Пороги лежат в `config/quality.yaml`. Одно заведение может быть конкурентом в двух нишах, например пекарня-кофейня, поэтому уникальность проверяется по паре идентификатора и ниши.

## Результат на данных 2026-11-20

На шести городах выполнено 402 проверки за 3 секунды, ошибок нет. Единственное предупреждение – в Ярославле нет вакансий парикмахеров на «Работе России», модель берёт для салона красоты медиану зарплат других профессий города и показывает это допущение в отчёте. Первая версия проверок нашла 600 повторов идентификаторов конкурентов в Москве, Санкт-Петербурге и Новосибирске. Разбор показал, что это заведения из двух ниш, и правило уникальности было уточнено.
