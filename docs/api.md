# API

API построен на FastAPI и запускается командой `uv run uvicorn geostart.api.main:app --reload`. Пути, параметры и примеры ответов описаны в [contracts.md](contracts.md), интерактивная документация доступна по адресу `/docs` запущенного сервиса.

## Режимы работы

| Режим | Переменная | Поведение |
| --- | --- | --- |
| Заглушки | `GEOSTART_USE_MOCKS=true` (по умолчанию) | ответы строятся из синтетических данных генератора, формулы в `src/geostart/api/mocks.py` |
| Реальные данные | `GEOSTART_USE_MOCKS=false` | пути с данными отвечают 503 с объяснением, пока не подключены расчёты модели (задача S1-F3) |

Пути `/health`, `/cities` и `/niches` работают в обоих режимах, так как читают только конфигурацию.

## Ошибки

Тексты ошибок пишутся по-русски в поле `detail` и объясняют, что сделать пользователю. Неизвестный город или ниша возвращают 404 со списком доступных кодов. Точка вне сетки города возвращает 422 с текстом «Точка вне границ города moscow, выберите место внутри МКАД» (для Тулы – «в границах города»).

## Заглушки

Выручка ячейки в заглушке растёт с числом жителей и работающих и падает с числом конкурентов в радиусе трёх колец H3 (около 500 м). Расходы включают аренду по условной ставке города, зарплаты со взносами 30%, себестоимость, налог 6% с выручки и прочие расходы. Уровень риска определяется рентабельностью: убыток означает высокий риск, рентабельность до 15% – средний, выше – низкий. Коэффициенты подобраны так, чтобы на карте встречались все три уровня риска, и не описывают реальную экономику ниш.

CORS разрешён для адресов из `GEOSTART_CORS_ORIGINS`, по умолчанию для сервера разработки Vite `http://localhost:5173`.
