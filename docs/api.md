# API

API построен на FastAPI и запускается командой `uv run uvicorn geostart.api.main:app --reload`. Пути, параметры и примеры ответов описаны в [contracts.md](contracts.md), интерактивная документация доступна по адресу `/docs` запущенного сервиса.

## Режимы работы

| Режим | Переменная | Поведение |
| --- | --- | --- |
| Реальные данные | `GEOSTART_USE_MOCKS=false` (по умолчанию) | карта читает `data/scores/<city>_<niche>.parquet`, конкуренты и адреса читаются из `data/processed/<city>/`, отчёт строится функцией `geostart.model.evaluate_location` |
| Заглушки | `GEOSTART_USE_MOCKS=true` | ответы строятся из синтетических данных генератора, формулы в `src/geostart/api/mocks.py` |

Пути `/health`, `/cities` и `/niches` работают в обоих режимах. В режиме реальных данных `/health` возвращает самую свежую дату сбора данных по городам, а при старте API читает файл `.env` из корня репозитория.

Перед запуском в режиме реальных данных нужны данные конвейера (`uv run python -m geostart.pipeline run --city all` или архив данных) и расчёт городов:

```
uv run python -m geostart.model score --city all --niche all
```

Модуль `src/geostart/api/data_backend.py` кэширует прочитанные файлы Parquet по пути и времени изменения, поэтому пересчёт города подхватывается без перезапуска API.

## Время ответа

На данных Москвы внутри МКАД ответ `/hexes` для 8717 ячеек весит около 1 МБ без сжатия и приходит примерно за 0,8 с, отчёт `/report` по адресу строится примерно за 1,4 с. Ответы больше 1000 байт сжимаются gzip, если клиент передаёт заголовок `Accept-Encoding: gzip`, что браузеры делают сами.

## Поиск адреса

Запрос разбивается на слова, буква «ё» приравнивается к «е», регистр не учитывается. Адрес попадает в выдачу, если содержит все слова запроса. Первыми идут адреса, у которых номер дома точно совпадает с числом из запроса, затем адреса, начинающиеся с первого слова, затем остальные по алфавиту. Выдача ограничена 10 адресами.

## Ошибки

Тексты ошибок пишутся по-русски в поле `detail` и объясняют, что сделать пользователю.

| Код | Когда |
| --- | --- |
| 404 | неизвестный город или ниша, город не загружен конвейером или не рассчитан моделью (в тексте команда, которую нужно выполнить) |
| 422 | точка вне границы города, неположительная площадь или ставка аренды, некорректные параметры запроса |

## Заглушки

Выручка ячейки в заглушке растёт с числом жителей и работающих и падает с числом конкурентов в радиусе трёх колец H3 (около 500 м). Расходы включают аренду по условной ставке города, зарплаты со взносами 30%, себестоимость, налог 6% с выручки и прочие расходы. Уровень риска определяется рентабельностью: убыток означает высокий риск, рентабельность до 15% – средний, выше – низкий. Коэффициенты подобраны так, чтобы на карте встречались все три уровня риска, и не описывают реальную экономику ниш.

CORS разрешён для адресов из `GEOSTART_CORS_ORIGINS`, по умолчанию для сервера разработки Vite `http://localhost:5173`.
