# Финансовый движок

Пакет `src/geostart/economics/` считает помесячную финансовую модель новой точки малого бизнеса на горизонте 12-120 месяцев. Движок отвечает на вопросы банка и предпринимателя о сумме вложений, сроке окупаемости, точке безубыточности, нагрузке кредита и подходящем налоговом режиме. Расчёт выполняется по 200 сценариям, поэтому каждый показатель возвращается диапазоном p10-p50-p90.

Движок не зависит от геоданных. Выручку он получает из одного из трёх источников, и модель Хаффа ГеоСтарта служит только одним из них. Благодаря такому разделению банк может передать в движок оценку выручки своей геоплатформы и получить финансовый расчёт без карты ГеоСтарта.

## Модули

| Модуль | Назначение |
| --- | --- |
| `norms.py` | загрузка и проверка нормативов из `research/economics/norms.yaml` |
| `sampling.py` | сценарии по оценке p10-p50-p90 и сводка результатов |
| `taxes.py` | УСН «Доходы», УСН «Доходы минус расходы», патент, взносы ИП за себя, НДС на УСН |
| `credit.py` | аннуитетный и дифференцированный график, коэффициент покрытия долга, предельный кредит |
| `engine.py` | помесячный расчёт и показатели, без чтения файлов |
| `service.py` | сборка входа из запроса API, выбор налогового режима, ответ API v2 |

Функции `engine.py` принимают массивы numpy и работают одинаково для любой ниши. Ниша влияет на расчёт только через параметры `research/niche_params/<niche>.yaml` и блок ниши в нормативах.

## Источники выручки

Выручка задаётся полем `demand` запроса:

- `geostart` – модель Хаффа по координатам точки, 200 сценариев параметров спроса из `research/niche_params`, ставка аренды берётся по району точки;
- `revenue` – внешняя оценка выручки в месяц p10-p50-p90, например от геоплатформы банка, поле `provider` попадает в ответ;
- `traffic` – трафик в день, конверсия и средний чек, выручка равна их произведению, умноженному на 30,4 дня.

Для источников `revenue` и `traffic` ставка аренды берётся медианой ставок города, если пользователь не задал свою. Плановая выручка понимается как средний месяц после выхода на план в ценах первого года.

## Сценарии

Оценка p10-p50-p90 превращается в 200 значений по кусочно-линейной функции квантилей. Значения на уровнях 0,1, 0,5 и 0,9 совпадают с оценкой, за пределами p10 и p90 функция продолжается с тем же наклоном и обрезается снизу нулём. Уровни берутся равномерной сеткой и перемешиваются генератором с зерном 2026, поэтому одинаковый запрос всегда даёт одинаковый ответ. Параметры затрат перемешиваются независимо друг от друга.

Площадь, штат, доля себестоимости, прочие расходы и вложения берутся из параметров ниши города. Значение, заданное в запросе, заменяет диапазон во всех сценариях.

## Помесячный расчёт

Месяц 1 соответствует первому месяцу работы точки, вложения делаются в месяц 0. Для каждого сценария и месяца движок считает:

- выручку как плановую выручку, умноженную на долю выхода на план, сезонный множитель календарного месяца и индекс цен;
- себестоимость как долю выручки;
- аренду как площадь, умноженную на ставку, с ежегодной индексацией;
- зарплату по медиане вакансий профессии в городе и взносы работодателя с учётом пониженного тарифа для кофеен;
- прочие расходы с ежегодной индексацией;
- EBITDA как выручку за вычетом перечисленных расходов;
- проценты и погашение кредита по графику;
- налоги по выбранному режиму.

Индексы растут ступенькой раз в 12 месяцев от открытия. Сезонность нормируется к среднему 1, поэтому годовая выручка после выхода на план не зависит от сезонности.

Вложения состоят из капитальных затрат, обеспечительного платежа по аренде и оборотного запаса. Обеспечительный платёж равен числу месяцев аренды из нормативов, оборотный запас равен числу месяцев себестоимости при плановой выручке. Оба возвращаются в последнем месяце горизонта. Стоимость бизнеса в конце горизонта не учитывается, и NPV получается консервативным.

## Налоги

Налоги считаются по календарным годам. Первый и последний год могут быть неполными, тогда фиксированные взносы ИП берутся пропорционально числу месяцев. Годовая сумма распределяется по месяцам пропорционально выручке.

| Режим | Расчёт |
| --- | --- |
| УСН «Доходы» 6% | 6% выручки уменьшаются на взносы работодателя и взносы ИП за себя, но не больше чем на 50% при наличии сотрудников |
| УСН «Доходы минус расходы» 15% | 15% от выручки за вычетом расходов, процентов, взносов ИП и вложений первого года, не меньше 1% выручки, убыток переносится на следующие годы |
| Патент | годовая стоимость патента города уменьшается на взносы так же, как УСН «Доходы» |

Взносы ИП за себя равны фиксированной сумме 57 390 ₽ в год и 1% дохода свыше 300 000 ₽, дополнительная часть ограничена 321 818 ₽. Для патента доходом считается потенциальный доход, равный стоимости патента, делённой на 6%. Для ООО взносы за себя не начисляются, налог на прибыль и дивиденды не моделируются.

Патент доступен только ИП в нише кофейни. В Москве стоимость берётся по ставке ЦАО, если точка в ЦАО или округ неизвестен, и по минимальной ставке для остальных округов. В Туле стоимость считается по площади зала, доля зала задаётся нормативом. Сценарий, в котором годовая выручка больше 20 млн ₽ или штат больше 15 человек, теряет право на патент и считается по УСН «Доходы», доля таких сценариев выводится в предупреждениях.

НДС на УСН определяется по годовой выручке календарного года. До 20 млн ₽ НДС не начисляется, до 272,5 млн ₽ применяется 5%, до 490,5 млн ₽ 7%, выше 22%. Переход на ставку внутри года не моделируется.

При `tax.regime = "auto"` движок рассчитывает все доступные режимы и выбирает режим с наименьшей медианой налогов за весь горизонт. Сравнение режимов возвращается в `tax.options`.

## Кредит

Сумма кредита задаётся абсолютной величиной или долей вложений и не может превышать вложения. Ставка и срок по умолчанию берутся из нормативов. Аннуитетный платёж считается по месячной ставке, равной годовой ставке, делённой на 12. Дифференцированный график гасит основной долг равными частями.

Коэффициент покрытия долга (далее – DSCR) считается по годам кредита как отношение операционного денежного потока к платежам по кредиту. В ответе есть DSCR первого года и минимальный DSCR по годам. Предельный кредит равен годовому денежному потоку после выхода на план, делённому на порог DSCR и на наибольший годовой платёж по кредиту в 1 ₽.

## Показатели

| Показатель | Определение |
| --- | --- |
| NPV | сумма дисконтированных операционных потоков и возврата залога и запаса за вычетом вложений, ставка по умолчанию равна ключевой ставке и премии за риск |
| IRR | годовая ставка, при которой NPV равен нулю, пусто, если поток не меняет знак |
| Окупаемость | первый месяц, в котором накопленный операционный поток покрывает вложения, с дробной частью, пусто, если вложения не окупаются за горизонт |
| Дисконтированная окупаемость | то же по дисконтированному потоку |
| Точка безубыточности | выручка в месяц, при которой прибыль после налогов в ценах первого года равна нулю, ищется делением отрезка с налогами выбранного режима |
| Единиц в день | точка безубыточности, делённая на средний чек или выплату за заказ и на 30,4 дня |
| Запас прочности | доля, на которую плановая выручка превышает точку безубыточности |
| Вероятность убытка | доля сценариев, где прибыль месяца после выхода на план отрицательна |

Пустые значения окупаемости при расчёте квантилей считаются бесконечно большими, пустые значения IRR и запаса прочности считаются бесконечно малыми. Если больше половины сценариев не окупаются, медиана окупаемости приходит пустой. Уровень риска определяется по вероятности убытка с порогами 20% и 50%, как в отчёте API v1.

Таблицы `monthly`, `years` и `steady_month` показывают один сценарий с медианным NPV, чтобы строки сходились по сумме. Полоса `cash_band` показывает p10-p50-p90 накопленного потока по всем сценариям.

## Нормативы

Файл `research/economics/norms.yaml` хранит общие нормативы и нормативы ниш. У каждого значения есть единица, источник и пояснение. Значение без подтверждённого источника отмечено `source: null` и выводится в допущениях ответа с пометкой «допущение без источника». Источники для таких значений собираются в задаче S2-Ц8.

| Норматив | Значение | Источник |
| --- | --- | --- |
| Ключевая ставка | 14% | решение Банка России от 23.10.2026 |
| Премия за риск | 6 п. п. | допущение |
| Инфляция и индексация цен | 6,5% в год | середина прогноза Банка России 6-7% |
| Индексация аренды и рост зарплат | 6,5% в год | допущение |
| Ставка кредита по умолчанию | 19% | ключевая ставка и 5 п. п., допущение до задачи S2-Ц3 |
| Срок кредита по умолчанию | 36 месяцев | допущение |
| Порог DSCR | 1,25 | допущение |

Для новой ниши в нормативы добавляется блок с выходом на план, сезонностью, оборотным запасом, обеспечительным платежом, долей зала и названием единицы продаж. Без такого блока API v2 возвращает ошибку 422 с текстом «Для ниши … нет нормативов финансового движка».

## Версии

Ответ содержит версии модели `economics-0.1.0`, нормативов, данных города и налогового исследования. Версия модели меняется при любом изменении формул, версия нормативов меняется при изменении `norms.yaml`.
