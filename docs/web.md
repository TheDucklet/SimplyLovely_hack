# Интерфейс ГеоСтарт

Интерфейс в web/ отображает прогноз выручки и окупаемости по ячейкам H3, конкурентов и финансовый отчёт по месту. Основной источник данных – локальный HTTP API. Для автономной разработки предусмотрены статические ответы из API в режиме заглушек.

## Запуск

Требуются Node.js 20.19 или новее и npm. CI использует Node.js 20.

Из корня репозитория подготовьте данные и запустите API:

```powershell
uv sync --locked
uv run python -m geostart.model score --city all --niche all
uv run uvicorn geostart.api.main:app --reload
```

Во втором терминале запустите интерфейс:

```powershell
cd web
npm ci
npm run dev
```

Откройте http://localhost:5173. Адрес разрешён настройкой API по умолчанию. При использовании http://127.0.0.1:5173 добавьте его в GEOSTART_CORS_ORIGINS на стороне API.

## Настройка

Скопируйте web/.env.example в web/.env.local. Файл .env.local исключён из Git. После изменения переменных перезапустите Vite, для production выполните сборку повторно.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| VITE_API_URL | http://127.0.0.1:8000 | Адрес API без /api/v1 |
| VITE_USE_MOCKS | sensitivity | `sensitivity` подменяет только анализ чувствительности, `false` направляет все запросы в API, `true` включает автономный пример Москвы |
| VITE_MAP_STYLE_URL | пусто | URL стиля MapLibre, пустое значение включает растровую подложку OpenStreetMap |

В режиме `true` браузер загружает примеры ответов и карту из локальной сборки. На карте остаются ячейки прогноза и конкуренты. В остальных режимах подложка использует настроенный сервер тайлов. Интерфейс использует системные шрифты, PDF содержит встроенный Roboto. Аналитика и внешние геокодеры не подключены. Worker MapLibre поставляется вместе с приложением, его URL формирует Vite.

В контуре банка задайте VITE_MAP_STYLE_URL на внутренний сервер. Сам стиль должен ссылаться на внутренние тайлы, спрайты и шрифты. На карте сохраняется атрибуция OpenStreetMap и data.mos.ru.

## Встраиваемый отчёт для ВТБ Бизнес

Элемент `geostart-report` показывает прогноз выручки, расходы, прибыль, окупаемость и риск для одной точки. Финансовый блок использует ту же модель, что и основной интерфейс. В нём доступны график денежного потока, показатели проекта, налоговый режим, кредитная нагрузка и таблицы по годам и месяцам. Карта, отдельные файлы стилей и внешние шрифты для подключения не нужны.

Соберите виджет из корня репозитория.

```sh
cd web
npm ci
npm run build:widget
```

Скопируйте `web/widget/dist/geostart-widget.js` к странице кабинета. Сборка проверяет, что результат состоит из одного JavaScript-файла и укладывается в 300 000 байт после gzip. Для API, доступного по путям `/api/v1/report` и `/api/v2/economics` на том же сайте, вставьте в HTML следующий фрагмент.

```html
<script src="geostart-widget.js"></script>
<geostart-report city="moscow" niche="coffee" lat="55.76" lon="37.62" api="/"></geostart-report>
```

Все пять атрибутов обязательны. Изменение любого атрибута обновляет отчёт. На странице можно разместить несколько элементов с разными адресами. Разметка и стили каждого экземпляра находятся в своём Shadow DOM.

| Атрибут | Значение |
| --- | --- |
| `city` | Код города из `/api/v1/cities`, например `moscow`. |
| `niche` | Код ниши из `/api/v1/niches`, например `coffee`. |
| `lat` | Широта от -90 до 90. Десятичный разделитель – точка. |
| `lon` | Долгота от -180 до 180. Точка должна попадать в выбранный город. |
| `api` | Базовый адрес сервиса без `/api/v1` и `/api/v2`. Допустимы `/`, путь вроде `/geostart` и полный адрес вроде `https://geostart.example`. |

Виджет отправляет координаты в `POST /api/v1/report` и `POST /api/v2/economics`. Запросы независимы. При ошибке одного раздела в нём появляется кнопка «Повторить запрос», другой раздел остаётся доступным. Для работы с банковской сессией разместите API за прокси на том же сайте, что и кабинет. Браузер передаёт сессионную cookie только запросам того же origin. Для демонстрации с отдельным сервером API включите origin страницы в `GEOSTART_CORS_ORIGINS`.

Для локальной проверки запустите API на порту 8000 по инструкции «Запуск». После сборки из каталога `web` запустите статический сервер.

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory widget
```

Откройте `http://localhost:4173/example.html`. Страница `web/widget/example.html` подключает готовый файл и запрашивает расчёт для кофейни в Москве. Проверьте диапазон выручки в кратком отчёте, раскройте таблицу по месяцам в финансовом блоке и сверьте суммы с ответами API.

## Финансовая модель точки

Выберите город и нишу, затем найдите адрес в поиске или нажмите на ячейку. Под отчётом по месту появится финансовая модель за 36 месяцев. Пустые поля площади и ставки аренды сохраняют параметры исследования. После изменения поля оба отчёта пересчитываются. Месяц открытия следует за текущим по календарю пользователя.

Линия на графике показывает медианный накопленный денежный поток проекта, полоса охватывает p10-p90. Метка показывает медианный срок возврата вложений по сценариям. Точные значения доступны с клавиатуры в таблице под графиком. Ниже приведены показатели окупаемости, вложения, налоговые режимы и кредитная нагрузка. Выберите продукт, задайте долю кредита, ставку и срок и нажмите «Применить условия». Для возраста бизнеса по умолчанию применяется значение движка. Ограничения продукта перечислены в предупреждениях отчёта.

Годовые результаты видны сразу. Для просмотра месячных строк, условий налоговых режимов и источников раскройте соответствующий раздел. На узком экране таблицы прокручиваются внутри панели. При ошибке API интерфейс показывает текст из `detail` и сообщения `errors` рядом с соответствующими полями.

`web/src/api/economicsTypes.ts` описывает запросы и ответы по `docs/api-v2.openapi.json`. Экономика точки и кредитные продукты в режиме `sensitivity` поступают из API. Только диаграмма факторов и четыре стресс-сценария используют подписанный демонстрационный пример из `web/src/mocks/sensitivity.json`. После подключения серверного пути задайте `VITE_USE_MOCKS=false` и перезапустите Vite. Ошибка анализа чувствительности оставляет финансовый отчёт доступным.

Для проверки откройте Москву и Тулу, по очереди выберите «Кофейня» и «Продукты у дома» в каждом городе. Сравните сумму NPV и месячные строки с ответом `POST /api/v2/economics` в сетевой панели браузера.

## Режим «что если»

Раскройте «Что если» в финансовом блоке. Поля чека и потока принимают изменение от -50 до +50%. Множители применяются к каждой из трёх оценок выручки исходного адреса. Например, рост чека на 10% и снижение потока на 20% дают 88% исходной выручки. В запросе сценария используется источник `revenue` с пометкой «что если». Движок заново строит сценарии выручки по трём оценкам, поэтому остальные показатели могут отличаться от расчёта по координатам даже при нулевом изменении спроса. Ставка аренды сохраняется для выбранного места, пока пользователь не задаст свою. Расходы, вложения, кредит и налоговый режим можно изменить независимо. При нулевой доле кредита условия платежей отключаются.

Через 500 мс после последнего изменения рядом с исходными показателями появляются результаты сценария. Более низкая безубыточная выручка, меньший платёж и более короткая окупаемость считаются улучшением соответствующего показателя. При отсутствии срока окупаемости сравнение сообщает, достигнут ли он в другом сценарии. Кнопка «Вернуть исходный расчёт» отменяет правки и показывает исходные значения сразу.

## Финансовая модель в бизнес-плане

Кнопка «Скачать черновик бизнес-плана» использует готовый исходный расчёт адреса, включая применённые условия кредита. Временный сценарий из режима «Что если» виден в сравнении на экране. В PDF включены карта, отчёт по месту и финансовая модель. Месячная таблица показывает первый год, годовая – операционный денежный поток за три года проекта. Суммы в таблицах округлены до десятых долей тысячи рублей. Раздел кредита показывает платёж, переплату, минимальное покрытие долга и предельную сумму. Источники допущений открываются по ссылкам. В автономном примере по адресу «Тестовая улица, 315» в PDF входит сохранённая финансовая модель.

## Устройство

web/src/api/types.ts повторяет модели src/geostart/schemas.py. web/src/api/client.ts выполняет запросы семи методов, обрабатывает detail и отмену запросов. web/src/components/MapView.tsx создаёт MapLibre и слой H3HexagonLayer через MapboxOverlay. Индексы H3 передаются слою без изменения разрешения. Область карты и кнопки масштаба имеют русские названия для программы чтения с экрана.

web/src/components/BankModal.tsx:BankModal открывает банковское действие в нативном диалоге. После открытия фокус переходит на кнопку «Понятно». Escape и кнопка закрывают окно и возвращают фокус на выбранное банковское действие, чтобы работу можно было продолжить клавиатурой.

Цвет выручки задаётся пятью группами с приблизительно одинаковым числом ячеек внутри города. Цвет служит для сравнения участков, точные суммы доступны в подсказке. Медиана на обзорной панели относится к распределению ячеек города.

При переключении на окупаемость меньшее число месяцев получает тёмно-синий цвет. Отсутствующий срок показан серым и подписан «Не окупается». Границы пяти групп можно раскрыть в легенде. Конкуренты отображаются ScatterplotLayer, их количество не влияет на число элементов DOM. При открытии страницы слой конкурентов выключен и включается флажком «Конкуренты» над картой, счётчик на флажке и список ближайших конкурентов в отчёте доступны всегда.

web/src/components/Search.tsx выполняет поиск через 300 мс после последнего ввода. Предыдущий запрос отменяется. Подсказки доступны клавишами вверх, вниз, Enter и Escape.

web/src/hooks/useLocationReport.ts выполняет запрос по выбранной точке сразу, а изменение площади и аренды объединяет с задержкой 500 мс. Одновременно выполняется один запрос отчёта, новое сочетание параметров ожидает его завершения. web/src/api/requestQueue.ts:createRequestQueue разделяет очередь между двумя отчётами. Ошибка одного запроса не блокирует следующий. Закрытие отчёта и смена города или ниши делают предыдущий результат неактуальным. Запросы карты отменяются при смене выбора.

web/src/components/ReportPanel.tsx показывает значения модели без самостоятельного пересчёта прибыли. Медиана прибыли рассчитана по сценариям и может отличаться от разницы медиан выручки и расходов, подробнее в docs/model.md. Денежные суммы округлены до рубля, дробные значения допущений сохраняются до трёх знаков. Пустые поля площади и аренды используют значения модели, неположительные значения не отправляются в API.

Панель отчёта располагается справа на широком экране и снизу на телефоне. Банковские кнопки открывают локальное окно пилота через HTML dialog. Браузер удерживает фокус внутри окна, Escape его закрывает. Переходов в реальные банковские сервисы нет.

## Обложка, приветствие и палитра

Страница открывается обложкой web/src/components/Landing.tsx, инструмент находится ниже в блоке с якорем #map высотой в экран без шапки. Шапка закреплена сверху и содержит ссылки на разделы обложки, переключатель кредитного специалиста и кнопку «Открыть карту». Цифры обложки и пример отчёта по Саянской улице, 3 к1 заданы константами в web/src/landing.ts по данным 2026-10-16 и сверке с РЦНИ из docs/product/metrics.md, при смене архива данных их нужно сверить. Метрика ROC AUC на сайте не показывается, она приведена в презентации и в docs/product/metrics.md. Шестиугольники обложки рисуются функцией heroHexes без изображений и внешних запросов.

При первом открытии web/src/components/WelcomeToast.tsx показывает приветствие в нативном диалоге с затемнением фона. Кнопка «Открыть карту» закрывает окно и переходит к инструменту, кнопка «Сначала прочитать о сервисе» закрывает окно и поднимает страницу к обложке, даже если адрес открыт с якорем #map. Escape и щелчок по фону просто закрывают окно. web/src/welcome.ts запоминает показ в localStorage под ключом geostart.welcome.seen. Если хранилище недоступно, приветствие показывается при каждом открытии, страница при этом работает.

Кнопка «Как считается оценка» в шапке и ссылка под предупреждением в панели отчёта открывают web/src/components/MethodologyDialog.tsx в нативном диалоге с затемнением фона. Окно описывает данные и их даты, порядок расчёта и ограничения модели, внизу показана версия данных из /health. Тексты лежат в web/src/content/methodology.ts и взяты из docs/data-sources.md, docs/model.md, config/pipeline.yaml, docs/security.md и docs/product/metrics.md, при обновлении данных их нужно сверить. На узком экране кнопка в шапке скрыта, окно открывается из отчёта.

Палитра сине-голубая: основной цвет #0a2e73, акцент #0077c8, светлые фоны #f2f6fc и #e9f1fb. Шкала выручки идёт от светло-голубого к тёмно-синему, непрозрачность ячеек 0,5. Подложка строится из векторного стиля OpenFreeMap Positron (данные OpenStreetMap, без ключа API). Стиль загружается в две синхронные карты MapLibre. Нижняя рисует стиль без слоёв подписей, над ней deck.gl рисует ячейки, конкурентов и выбранный адрес. Верхняя прозрачная карта без обработки событий рисует только подписи на русском (name:ru, иначе name) жирным почти чёрным шрифтом с белой обводкой, поэтому названия улиц и районов читаются над ячейками. Тот же разбор применяется к собственному векторному стилю из VITE_MAP_STYLE_URL. Режим interleaved deck.gl не используется, связка deck.gl 9.1 и MapLibre 6.14 в нём падает при отрисовке, а растровые тайлы CARTO с отдельными подписями с 2026 года требуют ключ. Конкуренты показаны белыми точками с синей обводкой, выбранный адрес голубым кругом. Зелёный цвет прибыли и янтарный цвет предупреждений сохранены как смысловые.

## Сравнение двух адресов

В готовом отчёте нажмите «Сравнить с другим адресом» и выберите второй адрес поиском или на карте. Первый отчёт сохраняется. Кнопки «Адрес 1» и «Адрес 2» задают, какое место меняют карта и поиск. Оранжевая точка на карте обозначает активный адрес. Площадь и аренда изменяются отдельно в каждом отчёте, оба параметра сохраняются при переключении активного адреса.

web/src/components/ComparisonPanel.tsx:ComparisonPanel показывает оба отчёта и таблицу сравнения выручки, общих расходов, прибыли и окупаемости. Разница рассчитывается как адрес 2 минус адрес 1. web/src/comparison.ts:compareReports использует показанные округлённые значения, деньги до рубля, срок до 0,1 месяца. Знак и подпись дублируют цвет. Рост выручки и прибыли выделен зелёным, рост расходов и срока красным. Равенство показано нулём. Если один или оба адреса не окупаются, строка срока содержит соответствующий текст без замены отсутствующего значения нулём.

Таблица появляется только для двух успешных расчётов с текущими параметрами, одним городом, нишей и версией данных. Во время пересчёта, включая задержку ввода, и при ошибках сравнение скрыто. Собственные сообщения и повторный запрос остаются в каждом отчёте. Переключение города или ниши сбрасывает оба отчёта и завершает сравнение. Кнопка «Завершить сравнение» и закрытие второго отчёта сохраняют первый. Закрытие первого отчёта завершает сравнение и закрывает оба.

На широком экране отчёты находятся рядом. На телефоне таблица сохраняет две колонки адресов и разницу, полные отчёты расположены последовательно в прокручиваемой панели. Горизонтальная прокрутка не требуется. В автономном режиме сравнение недоступно, так как комплект заглушек содержит один фиксированный отчёт.

## Проверка бизнес-плана

Режим доступен пользователям с правом `credit_check`. Нажмите «Проверка бизнес-плана», выберите город и нишу, затем найдите адрес или нажмите на карту. Площадь и аренду можно уточнить в панели адреса. Введите месячную выручку и сумму кредита в рублях, остальные поля заполняются по бизнес-плану. Для плана без заёмных средств введите сумму кредита 0. Ставку вводите в процентах годовых, срок кредита, окупаемость и возраст бизнеса – в месяцах.

По кнопке «Проверить бизнес-план» клиент отправляет `POST /api/v2/credit-check`. Блок `economics` содержит параметры точки и источник `geostart` с координатами, блок `plan` – значения заёмщика. ## Черновик бизнес-плана

Кнопка «Скачать черновик бизнес-плана» находится внизу готового отчёта. В режиме сравнения каждый из двух отчётов содержит свою кнопку, которая выгружает только его адрес, параметры и время расчёта. Названия города и ниши передаются обоим отчётам. Скачивается PDF формата A4 с финансовыми показателями и схемой участка на первой странице, допущениями и источниками на второй. Указаны дата получения расчёта по московскому времени и версия данных. Значения взяты из ответа API без повторного вычисления. Строковые допущения сохраняются, отсутствие источника обозначается явно. В автономном режиме документ помечается как демонстрационный.

Экспорт доступен после успешного расчёта. Изменение площади или аренды сразу блокирует кнопку до получения соответствующего ответа, включая задержку 500 мс перед запросом. При скачивании создаётся отдельный снимок отчёта, последующее изменение полей не меняет его содержимое.

web/src/businessPlan/definition.ts:createBusinessPlanDefinition задаёт документ. web/src/businessPlan/locationMap.ts:createLocationMap строит векторную схему по координатам точки, границе H3 и ближайшим конкурентам из отчёта. Показаны масштаб 200 м, север и круг 500 м по прямой. Уличная подложка в PDF не используется, схема создаётся без сетевых запросов и сохраняет атрибуцию источников.

web/src/businessPlan/download.ts:downloadBusinessPlan загружает pdfmake и встроенные шрифты отдельными частями сборки при первом скачивании. Внешние сервисы и системное окно печати не требуются. Ссылки источников открываются только для протоколов HTTP и HTTPS. Имя файла содержит город, нишу и дату расчёта. Список источников размещён в три колонки. Показано название сайта, ссылка сохраняет полный адрес публикации. Пометка «Не подтверждён» обозначает допущение без подтверждённого источника. На данных архива geostart_data_2026-10-16_v2.zip проверены обе ниши обоих городов с 29-35 допущениями, дополнительный отчёт сравнения и автономный пример. Каждый документ занимает два листа A4. При дальнейшем увеличении объёма текста требуется повторная проверка компоновки.

## Автономный режим

В `web/src/mocks/` лежат ответы первого спринта в режиме заглушек и сохранённые результаты финансовой модели по контракту v2. Комплект содержит Москву и кофейню, каждый файл меньше 2 МБ. Для поиска используйте «Тестовая». Отчёт в автономном режиме фиксирован и не пересчитывается для произвольного места или параметров.

```powershell
$env:VITE_USE_MOCKS = 'true'
npm run dev
```

Перед проверкой реального API удалите переменную из текущего терминала и перезапустите интерфейс:

```powershell
Remove-Item Env:VITE_USE_MOCKS
```

## Загрузка интерфейса (R-A4)

web/src/App.tsx подключает web/src/components/MapView.tsx через React.lazy и Suspense. Обложка, шапка, поиск и выбор города работают сразу, на месте карты до загрузки показывается индикатор «Загружаем карту». CSS MapLibre импортируется в самом MapView и приходит вместе с картой, поэтому контейнер карты задан правилом .map-canvas.maplibregl-map, которое не зависит от порядка загрузки стилей. web/vite.config.ts выносит MapLibre и deck.gl с luma.gl, loaders.gl, math.gl и probe.gl в отдельные части maplibre и deckgl, а вспомогательную функцию предзагрузки Vite в часть preload, иначе Rollup кладёт её в часть deckgl и стартовый код тянет deck.gl. pdfmake и шрифты по-прежнему загружаются только при экспорте PDF.

Замер 2026-11-01 в Edge без кэша, обе сборки подняты одновременно с одним API, по семь чередующихся прогонов, Fast 4G задан как 9 Мбит/с и задержка 60 мс.

| Показатель | До | После |
| --- | --- | --- |
| основной файл JS, сборка | 2 421 КБ, gzip 684 КБ | 273 КБ, gzip 85 КБ |
| основной файл JS по сети | 795 КБ | 98 КБ |
| первая отрисовка, лучший прогон без ограничения сети | 2,8 с | 0,9 с |
| первая отрисовка, лучший прогон Fast 4G | 1,6 с | 0,6 с |
| карта готова, медиана | 3,6-6,8 с | 5,9-6,7 с |

Медианы первой отрисовки на ноутбуке разработчика зашумлены задержками 3-5 с, которые возникают в обеих сборках, поэтому в таблице приведены лучшие прогоны. Время до готовой карты не уменьшается, карте нужны те же библиотеки, ответ API и тайлы подложки, они загружаются, пока посетитель читает обложку. Предупреждение Vite о частях больше 500 КБ остаётся для maplibre, deckgl, pdfmake и vfs_fonts, каждая из них соответствует одной библиотеке, порог chunkSizeWarningLimit не поднимался.

index.html и :root задают color-scheme only light. Без этого браузеры с принудительной тёмной темой (Auto Dark Mode в Edge и Chrome) затемняли страницу и делали карту чёрной.
