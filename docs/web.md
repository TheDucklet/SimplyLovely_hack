# Интерфейс ГеоСтарт

Интерфейс в web/ отображает прогноз выручки и окупаемости по ячейкам H3, конкурентов и финансовый отчёт по месту. Основной источник данных – локальный HTTP API. Для автономной разработки предусмотрены статические ответы из API в режиме заглушек.

## Запуск

Требуются Node.js 20.19 или новее и npm. CI использует Node.js 20.

Из корня репозитория подготовьте данные и запустите API:

```powershell
uv sync --locked
uv run python -m geostart.model score --city all --niche all
uv run uvicorn geostart.api.main:app --reload
```

Во втором терминале запустите интерфейс:

```powershell
cd web
npm ci
npm run dev
```

Откройте http://localhost:5173. Адрес разрешён настройкой API по умолчанию. При использовании http://127.0.0.1:5173 добавьте его в GEOSTART_CORS_ORIGINS на стороне API.

## Настройка

Скопируйте web/.env.example в web/.env.local. Файл .env.local исключён из Git. После изменения переменных перезапустите Vite, для production выполните сборку повторно.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| VITE_API_URL | http://127.0.0.1:8000 | Адрес API без /api/v1 |
| VITE_USE_MOCKS | false | true включает статические ответы без Python |
| VITE_MAP_STYLE_URL | пусто | URL стиля MapLibre, пустое значение включает растровую подложку OpenStreetMap |

Все запросы бизнес-данных идут в API. В автономном режиме JSON включаются в сборку и загружаются локально. Единственное внешнее обращение интерфейса – ресурсы подложки карты. Шрифты системные, аналитика и внешние геокодеры не подключены. Worker MapLibre поставляется вместе с приложением, его URL формирует Vite.

В контуре банка задайте VITE_MAP_STYLE_URL на внутренний сервер. Сам стиль должен ссылаться на внутренние тайлы, спрайты и шрифты. На карте сохраняется атрибуция OpenStreetMap и data.mos.ru.

## Устройство

web/src/api/types.ts повторяет модели src/geostart/schemas.py. web/src/api/client.ts выполняет запросы семи методов, обрабатывает detail и отмену запросов. web/src/components/MapView.tsx создаёт MapLibre и слой H3HexagonLayer через MapboxOverlay. Индексы H3 передаются слою без изменения разрешения.

Цвет выручки задаётся пятью группами с приблизительно одинаковым числом ячеек внутри города. Цвет служит для сравнения участков, точные суммы доступны в подсказке. Медиана на обзорной панели относится к распределению ячеек города.

При переключении на окупаемость меньшее число месяцев получает зелёный цвет. Отсутствующий срок показан серым и подписан «Не окупается». Границы пяти групп можно раскрыть в легенде. Конкуренты отображаются ScatterplotLayer, их количество не влияет на число элементов DOM.

web/src/components/Search.tsx выполняет поиск через 300 мс после последнего ввода. Предыдущий запрос отменяется. Подсказки доступны клавишами вверх, вниз, Enter и Escape.

web/src/hooks/useLocationReport.ts выполняет запрос по выбранной точке сразу, а изменение площади и аренды объединяет с задержкой 500 мс. Одновременно выполняется один запрос отчёта, новое сочетание параметров ожидает его завершения. web/src/api/requestQueue.ts:createRequestQueue разделяет очередь между двумя отчётами. Ошибка одного запроса не блокирует следующий. Закрытие отчёта и смена города или ниши делают предыдущий результат неактуальным. Запросы карты отменяются при смене выбора.

web/src/components/ReportPanel.tsx показывает значения модели без самостоятельного пересчёта прибыли. Медиана прибыли рассчитана по сценариям и может отличаться от разницы медиан выручки и расходов, подробнее в docs/model.md. Денежные суммы округлены до рубля, дробные значения допущений сохраняются до трёх знаков. Пустые поля площади и аренды используют значения модели, неположительные значения не отправляются в API.

Панель отчёта располагается справа на широком экране и снизу на телефоне. Банковские кнопки открывают локальное окно пилота через HTML dialog. Браузер удерживает фокус внутри окна, Escape его закрывает. Переходов в реальные банковские сервисы нет.

## Сравнение двух адресов

В готовом отчёте нажмите «Сравнить с другим адресом» и выберите второй адрес поиском или на карте. Первый отчёт сохраняется. Кнопки «Адрес 1» и «Адрес 2» задают, какое место меняют карта и поиск. Оранжевая точка на карте обозначает активный адрес. Площадь и аренда изменяются отдельно в каждом отчёте, оба параметра сохраняются при переключении активного адреса.

web/src/components/ComparisonPanel.tsx:ComparisonPanel показывает оба отчёта и таблицу сравнения выручки, общих расходов, прибыли и окупаемости. Разница рассчитывается как адрес 2 минус адрес 1. web/src/comparison.ts:compareReports использует показанные округлённые значения, деньги до рубля, срок до 0,1 месяца. Знак и подпись дублируют цвет. Рост выручки и прибыли выделен зелёным, рост расходов и срока красным. Равенство показано нулём. Если один или оба адреса не окупаются, строка срока содержит соответствующий текст без замены отсутствующего значения нулём.

Таблица появляется только для двух успешных расчётов с текущими параметрами, одним городом, нишей и версией данных. Во время пересчёта, включая задержку ввода, и при ошибках сравнение скрыто. Собственные сообщения и повторный запрос остаются в каждом отчёте. Переключение города или ниши сбрасывает оба отчёта и завершает сравнение. Кнопка «Завершить сравнение» и закрытие второго отчёта сохраняют первый. Закрытие первого отчёта завершает сравнение и закрывает оба.

На широком экране отчёты находятся рядом. На телефоне таблица сохраняет две колонки адресов и разницу, полные отчёты расположены последовательно в прокручиваемой панели. Горизонтальная прокрутка не требуется. В автономном режиме сравнение недоступно, так как комплект заглушек содержит один фиксированный отчёт.

## Ошибки API

Поле detail передаётся пользователю. API возвращает русские строки для ошибок 404 и 422, включая нарушения схемы запроса. Клиент также поддерживает массив detail как запасной вариант для совместимости с прежними версиями API, извлекая msg и loc из каждого элемента. На уровне интерфейса площадь и аренда проверяются до запроса.

## Автономный режим

JSON в web/src/mocks/ получены из приложения FastAPI через TestClient с GEOSTART_USE_MOCKS=true. Комплект содержит Москву и кофейню, каждый файл меньше 2 МБ. Для поиска используйте «Тестовая». Отчёт в автономном режиме фиксирован и не пересчитывается для произвольного места или параметров.

```powershell
$env:VITE_USE_MOCKS = 'true'
npm run dev
```

Перед проверкой реального API удалите переменную из текущего терминала и перезапустите интерфейс:

```powershell
Remove-Item Env:VITE_USE_MOCKS
```

## Проверка и сборка

```powershell
npm run lint
npm run build
npm run preview
```

Сборка лежит в web/dist/. Для просмотра production откройте http://localhost:4173. Адрес разрешён настройкой CORS API по умолчанию. Если GEOSTART_CORS_ORIGINS задана вручную, включите в неё адрес preview перед запуском API. Команда npm run lint проверяет eslint, форматирование prettier и запускает npm test. Девять тестов в web/tests/comparison.test.mjs проверяют разницу показателей, пустые сроки окупаемости и последовательную обработку запросов, включая ошибку. Для запуска используется встроенный модуль node:test, esbuild компилирует проверяемые модули TypeScript в памяти. Команда npm run format применяет форматирование.
