# Пояснение отчёта локальной моделью

Пояснение включается переменной `GEOSTART_EXPLANATIONS=true`. По умолчанию функция выключена, поэтому обычный отчёт не зависит от установленной языковой модели.

Сервис обращается только к loopback-адресу `127.0.0.1`, `localhost` или `::1`. Внешние URL отклоняются до отправки запроса. По умолчанию используется Ollama-совместимый endpoint `http://127.0.0.1:11434/api/generate` и модель `qwen2.5:3b`.

Модель получает JSON отчёта и должна сформировать короткое пояснение на русском языке. Ответ проходит две проверки. Ограничивается длина текста и каждое числовое значение сверяется с числами исходного отчёта. Если локальная модель недоступна, URL не является loopback-адресом или число не прошло проверку, API возвращает отчёт без пояснения и пишет причину в журнал.

Для локальной проверки нужен заранее загруженный образ модели. После запуска модели задайте переменные из `.env.example`, перезапустите API и откройте отчёт по адресу. Тесты подменяют локальный endpoint и проверяют запрет внешнего адреса, разбор ответа и отбрасывание выдуманных чисел.
