# Комплект сдачи второго спринта

Документ фиксирует состояние материалов S2-П3 и порядок проверки перед передачей жюри.

## Текущий режим показа

| Проверка | Состояние на 2026-11-27 |
| --- | --- |
| Основной адрес | `http://127.0.0.1:8080` |
| Локальный Docker-стенд | доступен, 4 из 4 endpoint-ов отвечают успешно |
| VPS | отложен до отдельного решения команды |
| Часовая проверка VPS | workflow `Public stand health`, запускается после задания `GEOSTART_PUBLIC_URL` |

Для текущей демонстрации достаточно локального стенда. Секреты SSH и токены в репозиторий не добавляются.

## Что показываем

- карта и отчёт по адресу в шести городах;
- семь ниш с расчётом спроса и финансовой модели;
- API v2 для экономики, проверки бизнес-плана и банковских сценариев;
- автономная подложка PMTiles без внешних запросов во время работы стенда;
- OIDC-заглушка, роли, журнал обращений и схема интеграции с ВТБ Бизнес;
- архив данных с манифестом, контрольными суммами и отчётом качества.

## Локальный запуск перед записью

1. Распакуйте архив данных в корень клона.
2. Выполните `docker compose -f compose.demo.yml up -d --build --wait`.
3. Откройте `http://127.0.0.1:8080` и проверьте карту, поиск адреса и отчёт.
4. Выполните `python scripts/check_stand.py --url http://127.0.0.1:8080`.
5. Запишите видео длительностью до трёх минут с локального стенда.

Презентацию и видео нужно обновить по актуальному локальному интерфейсу. Материалы первого спринта не считаются комплектом второго спринта без такой проверки.
